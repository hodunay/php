Напиши отказоустойчивый цикл чтения CSV, где числа используют десятичную запятую и пробел как разделитель тысяч, а также добавь виртуальное накопительное списание остатков при обработке пачки заказов».

> «Проанализируй фрагмент лога веб-сервера с ошибками 503 и сопоставь его с расписанием задач crontab. Выяви скрытую причину перегрузки ресурсов лимитов LVE хостинга и предложи 3 действия по оптимизации».

- Где ИИ ошибся и как Вы это заметили:
> В задании 01 ИИ сгенерировал классическую сигнатуру функций fgetcsv() / fputcsv() без учета жестких изменений в PHP 8.4+. При локальном тестировании на свежей версии PHP интерпретатор выбросил PHP Deprecated/Fatal error. Пришлось вручную передавать дефолтные параметры экранирования '"', "\\".
> ИИ полностью пропустил скрытую аномалию данных в nomenclature_1c.csv — наличие невидимого UTF-8 BOM-маркера в первой строке файла. Из-за этого первый артикул TS-1001 не сопоставлялся с базой. Ошибка была замечена в ходе ручного дебага и исправлена добавлением блока очистки байтов strpos($sku, "\xEF\xBB\xBF").

- Что Вы проверяли вручную:
> Валидность структуры результирующего CSV-отчета через парсер, математическую точность работы класса расчета НДС и скидок после исправления багов.

## Если бы это шло в прод
1. Перенос контура хранения заказов и очередей синхронизации из файлов (json/csv) в реляционную базу данных с транзакционным механизмом (InnoDB). Введение уникальных хэшей транзакций для исключения задвоения документов при повторных запросах со стороны API маркетплейсов.
2. Изоляция ошибок в очередях. Переработка логики воркеров обмена. Ошибки бизнес-логики (например, HTTP 422 — нет контрагента в 1С, как в inc3) должны маркировать задачу как failed и отправлять её в карантин для ручного разбора, а не блокировать продвижение всей последующей очереди.
3. Мониторинг, логирование и алертинг. Интеграция разработанного в Задании 06 прототипа умного AI-мониторинга. Настройка мгновенных алертов в Telegram/Slack дежурному инженеру при превышении времени нахождения задач в статусе pending более 15 минут.
